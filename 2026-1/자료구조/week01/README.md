## 1. 자료구조란?

자료구조(Data Structure)는 데이터를 효율적으로 저장하고 관리하며  
필요할 때 빠르게 사용할 수 있도록 조직하는 방법이다.

프로그램의 성능은 데이터를 어떻게 구조화하느냐에 따라 크게 달라질 수 있다.

---

## 2. 자료구조와 알고리즘

자료구조와 알고리즘은 서로 밀접한 관계를 가진다.

- 자료구조 : 데이터를 저장하고 관리하는 방법
- 알고리즘 : 데이터를 처리하는 절차 또는 방법

좋은 자료구조를 사용하면 알고리즘의 효율도 높아질 수 있다.

---

## 3. 추상 데이터 타입 (ADT)

추상 데이터 타입(Abstract Data Type)은

데이터의 구조와 연산을 정의하지만  
구체적인 구현 방법은 숨기는 개념이다.

예시
- Stack
- Queue
- List
- Tree

---

## 정리

자료구조는 데이터를 효율적으로 저장하고 관리하기 위한 방법이며  
알고리즘과 함께 프로그램 성능에 중요한 영향을 미친다.
